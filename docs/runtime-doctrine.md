# Runtime Doctrine: The Antigravity Engine

This document defines the foundational boundaries and philosophical constraints of the execution runtime. If a pull request violates any of these doctrines, it must be rejected regardless of its perceived utility.

## 1. AI is External
The runtime is not a cognitive agent; it is an evidence capture mechanism. AI operates strictly as an external sidecar.
- **Forbidden:** Generating Prompts, calling LLM endpoints, semantic inference during crawl loops.
- **Required:** AI only consumes the fully completed, deterministic `bundle-v1.json` generated by the runtime.

## 2. Replay is Canonical Truth
The system must be capable of perfectly regenerating its results from canonical history.
- **Forbidden:** Parallel role orchestration, volatile raw IDs bridging replaying epochs.
- **Required:** Checkpointing strictly bounds the Replay Seed, Graph State, and Evidence Lineage. Checkpointing raw cookies or local storage is prohibited.

## 3. Confidence Controls Scope
Confidence metrics are scales, not gates. 
- **Forbidden:** "Blocking" exploration entirely because of low confidence.
- **Required:** Low confidence triggers conservative traversal (Level 1). High confidence triggers full differential expansion (Level 3). Confidence determines *how deep* we go, not *if* we go.

## 4. Candidates are Deterministic Structures
The runtime does not "think." It performs structural mathematics.
- **Forbidden:** "Hypothesis", "Inference", "Guessing", "Probabilistic Scoring".
- **Required:** Graph signals are transformed via named deterministic rules (e.g., `CrossRoleOwnershipMismatch`) into strictly typed `InvestigationCandidate` JSON objects.

## 5. Human Provides Intent. System Performs Execution.
The system scales human actions; it does not replace the human's strategic intuition.
- **Forbidden:** Asking the system to "find a target" or "guess the login."
- **Required:** The human explicitly bootstraps the workspace with a seed (target, credentials, minimal traversal). The runtime autonomously expands that specific intent.

## 6. Knowledge is Disposable
The `KnowledgeGraph` is an investigation-local tool, not a global search engine.
- **Forbidden:** Reusing graphs across different workspace targets. Building a unified "memory" of all targets.
- **Required:** The Graph is strictly 1:1 mapped to a Workspace. When the investigation is complete, the `dispose()` method is explicitly called, and the graph is archived or destroyed.

## 7. Evidence is Portable
The runtime generates proof that humans (and models) can trivially interact with offline.
- **Forbidden:** Coupling evidence to proprietary database states or internal class instances.
- **Required:** All evidence must be serializable to the `bundle-v1.json` interface and strictly assembled by the `AiExportAdapter`.

## 8. Coordinators Coordinate. Adapters Assemble.
Code boundaries are strictly policed by role.
- **Forbidden:** `InvestigationCoordinator` interpreting candidates. `AiExportAdapter` summarizing output.
- **Required:** Coordinators only move state and invoke engines. Adapters only write text to disk. Neither is allowed to contain domain logic.
